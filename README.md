# CS50: Ejercicios, Entregables y Apuntes

Este repositorio reúne una selección de los ejercicios y proyectos más interesantes desarrollados a lo largo del curso CS50. El contenido está compuesto tanto por entregables oficiales de la plataforma como por documentos y scripts creados a manera de apuntes personales de estudio.

## 🚀 Objetivos del Repositorio
* **Demostrar aprendizaje:** Mostrar la evolución en la resolución de problemas lógicos y algoritmos.
* **Documentación:** Servir como base de conocimiento personal para consultas futuras de sintaxis y lógica.
* **Proyectos Clave:** Compartir soluciones optimizadas a los retos planteados en el curso.
